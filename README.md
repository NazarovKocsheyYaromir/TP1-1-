# Лабораторная работа №1 — Keeper<Base>: Печатные издания

## Структура

- `Exceptions/Exceptions.h` — иерархия пользовательских исключений
  (`KeeperException` и производные: `MemoryAllocationException`,
  `InvalidIndexException`, `FileException`, `InputException`,
  `EmptyContainerException`, `UnknownTypeException`).
- `Base/` — абстрактный базовый класс `Base` («Печатное издание»):
  ФИО и список произведений; чисто виртуальные `print()`, `clone()`,
  `getType()`, `getTypeName()`, `editMenu()`.
- `Poet/` — класс `Poet` (Поэт): ФИО, годы жизни, произведения.
- `Novelist/` — класс `Novelist` (Романист): ФИО, годы жизни,
  произведения, краткая биография.
- `SciFiWriter/` — класс `SciFiWriter` (Фантаст): ФИО, произведения,
  признак «сняты ли фильмы по книгам».
- `Keeper/` — класс-контейнер `Keeper`: динамический массив `Base**`
  с ручным управлением памятью (без STL), добавление/удаление объектов,
  полное сохранение в бинарный файл и полное восстановление из файла.
- `main.cpp` — точка входа программы с интерактивным консольным меню.

## Особенности реализации

- Всё выделение памяти — динамическое (`new`/`delete`), без
  STL-контейнеров (`std::vector`, `std::string` и т.п. не используются
  для хранения данных — только `char*`/`char**`/`Base**`).
- У каждого класса (`Base`, `Poet`, `Novelist`, `SciFiWriter`, `Keeper`)
  реализованы: конструктор по умолчанию, параметризованный конструктор,
  конструктор копирования, деструктор и оператор присваивания —
  каждый вызов сопровождается выводом в консоль (класс + тип операции).
- `Keeper` использует глубокое копирование через виртуальный `clone()`.
- Сохранение/восстановление — бинарный формат, включающий тип объекта,
  что позволяет `Keeper::loadFromFile` корректно воссоздавать нужный
  производный класс.
- Все проверки корректности ввода/индексов оформлены через исключения
  с поясняющим текстом и перехватываются в `main()`.
- На Windows консоль автоматически переключается в кодировку UTF-8
  (`SetConsoleOutputCP`/`SetConsoleCP`), чтобы кириллица отображалась
  корректно. Если всё же видите "кракозябры" — выполните в cmd команду
  `chcp 65001` перед запуском и используйте Windows Terminal
  (в старом cmd.exe со стандартным растровым шрифтом кириллица иногда
  всё равно отображается некорректно — переключите шрифт консоли на
  Consolas/Lucida Console в её свойствах).
- Игнорируем предупреждения (`-Wall -Wextra`)

## Сборка

```bash
g++ -std=c++17 -Wall -Wextra -o lab1_app main.cpp \
    Base/Base.cpp Poet/Poet.cpp Novelist/Novelist.cpp \
    SciFiWriter/SciFiWriter.cpp Keeper/Keeper.cpp
```

## Запуск

```bash
./lab1_app
```

Программа предложит меню:
1. Добавить объект (Поэт/Романист/Фантаст)
2. Удалить объект
3. Показать все объекты
4. Редактировать объект (у каждого класса своё подменю)
5. Показать количество объектов
6. Сохранить в файл
7. Загрузить из файла
8. Очистить контейнер
0. Выход
